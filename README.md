# VidyaPramaan

An APAAR ID-based student enrolment verification and governance platform for AICTE-approved institutions. 

VidyaPramaan treats college-submitted student records as **enrolment claims** validated through a five-layer verification pipeline — verifying APAAR academic identity, central/state seat allotment evidence (JoSAA/CET), independent student confirmation via APAAR-linked contacts, cross-institutional duplicate detection, and digital seat ledger compliance citing AICTE Approval Process Handbook (APH) rules. Verified records are issued as tamper-proof, cryptographically signed W3C Verifiable Credentials with scannable QR codes for instant offline verification.
